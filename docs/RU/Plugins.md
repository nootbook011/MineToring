# Плагины MineToring

Плагины — это модификации или расширения для базовых классов ядра MineToring. Они обеспечивают независимую поддержку нового функционала, который не предоставляется ядром по стандарту.

---

## 🛠 Виды плагинов

MineToring поддерживает различные пути модификации основных классов в зависимости от требуемой глубины интеграции:

| Тип | Описание | Пример реализации |
| :--- | :--- | :--- |
| **Расширения** | Предоставляют новые методы для стандартных классов на основе их экземпляров. | `await Bot.init({ plugins: [myPlugin] })` |
| **Модификации** | Используют наследование целевого базового класса ядра для полного контроля над ним. | `class MyBot extends BaseBedrockBot { }` |
| **Адаптеры** | Служат прослойками для сторонних библиотек декодирования сетевых данных (payload). | [Базовый класс адаптера](../../src/BaseClasses/ValidateAdapter/BaseMainAdapter.js) |

---

## 📦 Встроенные плагины

MineToring включает встроенные плагины для обеспечения базового функционала «из коробки». Они поставляются как зависимости внутри базовых классов и хранятся в блоке **Main**.

### 1. Плагины: Расширения
Эти плагины хранятся в папке с пакетами и загружаются динамически в зависимости от версии игры:

* **ClientPacketSession**: Автоматическое управление пакетами.
* **ActionsModule**: Готовые методы для управления ботом.

### 2. Плагины: Модификации
Данные плагины хранятся в папке **Modify**:

* **BedrockBot**: Продвинутая версия клиента, предоставляющая расширенный функционал.

### 3. Плагины: Адаптеры
Хранятся в директориях с припиской **Adapters**. Благодаря им MineToring может работать с любыми библиотеками декодирования, не ограничиваясь стандартной `prismarine-chunk`:

* **PrismarineAdapters**: Базовые адаптеры для популярной библиотеки Prismarine-chunk.
