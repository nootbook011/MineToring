# Плагины MineToring

Плагины представляют собой модификации или расширения базовых классов ядра MineToring. Они позволяют независимо добавлять новый функционал, не предусмотренный стандартным ядром системы.


## Виды плагинов

MineToring поддерживает различные подходы к модификации основных классов, в зависимости от требуемой глубины интеграции:

| Тип | Описание | Пример реализации |
| :--- | :--- | :--- |
| **Расширения** | Добавляют новые методы к экземплярам стандартных классов без изменения их структуры. | `await Bot.init(options, { plugins: [myPlugin] })`, `Bot.loadPlugin(myPlugin)` |
| **Модификации** | Позволяют полностью контролировать базовый класс через наследование. | `class MyBot extends BaseBedrockBot { }` |
| **Адаптеры** | Обеспечивают интеграцию с внешними библиотеками для декодирования сетевых данных. | [Базовый класс адаптера](../../src/BaseClasses/ValidateAdapter/BaseMainAdapter.js) |

---

## Как сделать свой плагин?

Для создания плагина реализуйте его как класс, расширяющий или модифицирующий функционал базовых классов MineToring. Метод загрузки зависит от типа плагина.

---

### Расширения
Стандартное расширение функционала.
* **Создание**: Используйте встроенный базовый класс **BasePlugin**, наследуя его и добавляя нужный функционал. 
* **Загрузка**: Загружайте плагин методом `.loadPlugin(plugin)` в класс, поддерживающий расширения.
* **Пример**: [PluginsExample.js](../../tests/client/PluginsExample.js)

---

### Модификации
Обеспечивает полный контроль над целевым классом.
* **Создание**: Наследование от целевого базового класса.
* **Пример**: [BedrockBot.js](/src/MainClasses/Modify/Client/BedrockBot.js)

---

### Адаптеры
Специализированные плагины для совместимости с библиотеками декодирования сетевых данных. Требуют знаний API целевой библиотеки.
* **Создание**: Наследуйте адаптер от **базового класса адаптера** и реализуйте логику декодирования.
* **Загрузка**: Передавайте адаптер как зависимость при инициализации: `Bot.init(options, { ValidateAdapter: Adapter })`
* **Пример**: [PrismarineAdapter.js](../../src/MainClasses/PrismarineAdapters/PrismarineAdapter.js)

---

## Встроенные плагины

MineToring поставляется с встроенными плагинами, обеспечивающими базовый функционал. Они интегрированы как зависимости в базовые классы.

### 1. Плагины: Расширения
Используются как зависимости базовых классов, так же могут загружаться динамически в зависимости от версии:

* **Logger**: Вспомогательный класс для логирования.
* **BotPacketController**: Служит мостом для пакетов и базового класса бота.
* **DataBase**: Динамически загружает пакетные парсеры для базовых классов.
* **ClientPacketSession**: Обеспечивает автоматическое управление сетевыми пакетами.
* **ActionsModule**: Предоставляет готовые методы для управления ботом.

### 2. Плагины: Модификации
Находятся в папке **Modify**:

* **BedrockBot**: Улучшенная версия клиента с расширенными возможностями.

### 3. Плагины: Адаптеры
Располагаются в директориях с суффиксом **Adapters**. Позволяют работать с различными библиотеками декодирования, не ограничиваясь стандартной `prismarine-chunk`:

* **PrismarineAdapters**: Стандартные адаптеры для библиотеки Prismarine-chunk.
