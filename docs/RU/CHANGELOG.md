## 0.7.5

### Основные изменения

* **Поддержка блоков и биомов**: MineToring теперь поддерживает блоки! Классы `BedrockChunk` и `BedrockSubChunk` больше не просто хранят сетевые данные, теперь они умеют самостоятельно декодировать их и заполнять собственные структуры информацией о блоках и биомах. Появилось множество удобных методов API для доступа к блокам по координатам, высокоэффективного поиска блоков и итерации по блокам прямо внутри измерения. [Подробнее в документации API](./API.md).
* **Поддержка скинов**: Добавлен новый класс `BedrockSkin`, который хранит данные о скинах игроков. Вместе с ним добавлены новый метод API `ActionsModule.changeSkin` и новый блок настроек для бота. Благодаря этому теперь можно указывать пути к скину, плащу и кастомной геометрии скина бота, а также менять скин прямо во время игры. [Подробнее в документации API](./API.md).
* Добавлены новые опции конфигурации бота: `fastLoading`, `loadingTimeout`, `loginWithDifferentSkins` и `ignoreProtocolErrors`.
* Добавлено новое свойство `BedrockPlayer.structure`, которое указывает, в какой структуре сейчас находится бот. *Обратите внимание: это свойство доступно только у экземпляра класса, представляющего игрока бота в мире.*

### Технические изменения

* **Рефакторинг архитектуры**: Ключевым изменением этого обновления пересмотр архитектуры MineToring. Проект временно перешел на монолитное ядро, в связи с чем были **полностью удалены все элементы мультиверсионности, включая структуры, связанные с протоколом, и сам класс** `BedrockProtocol`. Теперь разработка сосредоточится на обеспечении стабильности в диапазоне версий игры **1.21.0 - 1.21.100**. Все файлы протокола 1.21 были перенесены в основное ядро.
    * **Почему принято такое решение?** В данный момент проект сосредоточен на добавлении новых и улучшении существующих методов API, а также на активном исправлении ошибок в ядре. Прежняя структура протоколов оказалась слишком ненадежной и переусложненной, она замедляла разработку и не давала практической пользы.
    * **Что будет дальше?** Мы находимся в поиске нового решения для поддержки разных версий игры. Текущее монолитное устройство только временное, в будущем ему на смену придет более продуманная архитектура.
* **Улучшенная авторизация**: Доработан процесс авторизации и подключения бота к серверу в модуле `ClientPacketSession`. Теперь бот стабильнее заходит на сервер и загружает мир.
* **Множество багфиксов**: Исправлены ошибки и баги прошлых версий.
