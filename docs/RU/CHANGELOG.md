# 0.7.0

## Основные нововведения

* **Поддержка сущностей (Entities)**: MineToring теперь поддерживает сущностей! Добавлена поддержка отображения всех существ в радиусе прорисовки бота.
    * *На данный момент поддерживаются:* обычные сущности/мобы и игроки.
* **Интеграция EventEmitters**: Классы `BedrockWorld`, `BedrockDimension`, `BedrockEntity`, `BedrockPlayer` и `ActionsModule` теперь поддерживают **EventEmitter**. 
    * Доступ к событиям осуществляется через метод `.events`.
* **BedrockServer**: Новый класс BedrockServer!. Теперь вся техническая информация из пакета `start_game`, а также актуальный полный список игроков с их базовыми данными, находятся внутри этого класса.
* **examples**: Папка `tests` больше не используется для хранения демонстрационного кода. Все примеры переехали в директорию [`examples`](../../examples).
* **API Документация**: Теперь MineToring ведет API документацию! 
    * Она будет обновлятся и дополняться в соответствии с исходным кодом. 
    * Она предоставляут актуальную и подробную информацию о методах, событиях EventEmitter и содержанием всех динамических методов и переменных внутри классов ядра.
    * [**Смотрите документацию API**](API.md)

## Технические изменения

* **Глобальное обновление архитектуры**: Проведен масштабный рефакторинг ядра и протоколов.
    * Проведена глубокая чистка кода и оптимизация структуры.
    * Папки в директории `src` получили логичные и понятные названия.
* **Система плагинов**: Устаревшая система `Engines` полностью заменена новой системой плагинов. Это обеспечивает более современное и производительное API для расширения функционала.
* **Динамический `ProtocolLoader`**: Класс был полностью переписан.
    * Теперь основной класс протокола доступен через статический метод без необходимости ручной валидации.
    * Загрузка стала динамической: любой `default export` из JS-файла в папке протокола подгружается автоматически.
    * Модуль `DataBase` признан устаревшим и полностью удален из проекта.
*   **Исправления ошибок**: Устранено множество мелких багов и ошибок.
