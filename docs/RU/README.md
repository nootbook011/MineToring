**Продвинутый фреймворк**, построенный поверх библиотеки **Bedrock-Protocol**, предоставляющий высокоуровневый API для создания ботов в Minecraft Bedrock.

## Ключевые особенности

**MineToring** - Это один из первых проектов, который предоставляет **высокоуровневый API** для создания ботов и работы с экосистемой **Minecraft Bedrock Edition**.

---

- **Поддержка сущностей**: Бот видит всех сущностей, игроков и предметы в радиусе прорисовки и знает всю доступную информацию о них: от атрибутов и состояний до устройства, с которого играет пользователь.
- **Доступность данных**: Полный доступ к данным мира, сущностей, блоков и биомов. Вам доступно множество высокоуровневых методов для работы с этими данными.
- **Прогрузка територии**: Полноценная загрузка чанков мира вокруг с поддержкой кэширования и нулевой потерей данных.
- **Высокоуровневые действия**: Готовые действия бота, позволяющие автоматически возрождаться после смерти или отправлять команды в чат.
- **Поддержка EventEmitters**: Классы сущностей, игроки и многие другие классы имеют встроенную поддержку событий через метод `.events`. Это позволяет подписываться на обновления конкретной сущности, мира или высокоуровневого действия.
- **Автоматическое обновление**: Полностью автоматическое обновление всех сущностей, данных мира и измерений. Вы всегда будете видеть максимально актуальные данные, присылаемые сервером.

---

* **Поддерживаемые версии Minecraft Bedrock:** `1.21.0, 1.21.2, 1.21.21, 1.21.30, 1.21.42, 1.21.50, 1.21.60, 1.21.70, 1.21.80, 1.21.90, 1.21.93, 1.21.100`.
* **Протестировано на версиях:** `1.21.0, 1.21.50, 1.21.100`.

## Возможности API
Имеющиеся высокоуровневые API интерфейсы для взаимодействия с данными и механиками **Minecraft Bedrock**. ([см. документацию API](#документация-api))

### Собственный клиент
Модифицированный клиент на базе библиотеки **Bedrock-Protocol** с множеством улучшений для обеспечения удобного высокоуровневого взаимодействия.

- **Менеджер настроек**: Удобный класс для хранения конфигурации клиента, обеспечивающий автодополнение в IDE.
- **Базовый клиент**: Обеспечивает базовое сетевое взаимодействие с удалённым сервером по протоколу Bedrock. Встроена генерация и сохранение данных сессии клиента для повторной авторизации. Возможны многократные переподключения к серверу без потери сессии. Предоставляет методы для низкоуровневого управления сетью (отправка/ожидание пакетов), высокоуровневые методы ожидания состояний соединения бота и многое другое.
- **Высокоуровневый бот**: Бот, построенный на базе клиента, автоматически управляет сетью через высокоуровневые методы API и эмулирует официальный клиент игры. Он дает доступ к остальным частям API фреймворка на основе данных целевого сервера.

### Мультиверсионность
Поддержка протокола Bedrock для обработки сетевых пакетов и поддержки разных версий игры.

- **Загрузчик протокола**: Собственный загрузчик динамических данных протокола для выбранной версии игры, благодаря ему MineToring поддерживает множественные версии игры.
    - **Протокол**: Классы ядра используют парсеры, декодеры, обработчики и модули из динамического протокола для обеспечения работы единого ядра под разные версии игры.

### Работа с данными
Собственная высокоэффективная архитектура для обработки игровых данных.

- **Сервер**: Техническая информация о сервере и полный список подключённых игроков.
- **Мир**: Данные о времени, измерениях, игровые правила (gamerules), эксперименты и общая информация о мире.
- **Сущности**: Данные сущностей, игроков и предметов. Методы для получения состояний сущности, информации об устройстве игрока и его скине, информация лежащего на земле предмета.
- **Измерения**: Методы для получения и поиска блоков и биомов внутри измерения по локальной карте чанков.
- **Чанки**: Хранение и обработка данных биомов и подчанков.
    - **Подчанки**: Информация о палитре и блоках внутри подчанка.
    - **Биомы**: 2D/3D-карта биомов в пределах чанка.

## Установка
Установите текущую версию Node, затем в терминале запустите:
```bash
npm install minetoring
```

Для обновления пакета MineToring и его зависимостей запустите:
```bash
npm update
```

## Начало работы

Больше примеров можно найти в [папке examples](/examples/).

```javascript
import { Bot, BotOptions } from 'minetoring'

// Для упрощенной настройки в IDE.
const opt = new BotOptions()
opt.configServer({
    host: '127.0.0.1',
    port: 19132
})
opt.configClient({
    username: 'Steve'
})

const bot = new Bot()
// Асинхронная инициализация для динамического импорта модулей протокола
await bot.init(opt)
await bot.connect()

// Необходимо для уверенности, что клиент загружен на момент отправки пакетов
await bot.waitUntilSpawn()

// await необязателен для действий, когда вам не нужно ждать обработки пакета сервером
await bot.actions.sendMessage('Hello World!')
bot.disconnect()
```
