# MineToring

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Framework](https://img.shields.io/badge/Base-PrismarineJS--Bedrock--Protocol-green)](https://github.com/PrismarineJS/bedrock-protocol)

**MineToring** это продвинутый фреймворк-надстройка, построенный поверх библиотеки **Bedrock-Protocol**. Он предоставляет высокоуровневые инструменты для создания ботов и систем мониторинга, автоматизируя управление данными мира и сессиями.

* **Поддерживаемые версии Minecraft Bedrock:** `1.18.0, 1.18.11, 1.18.30, 1.19.1, 1.19.10, 1.19.20, 1.19.21, 1.19.30, 1.19.40, 1.19.41, 1.19.50, 1.19.60, 1.19.62, 1.19.63, 1.19.70, 1.19.80, 1.20.0, 1.20.10, 1.20.30, 1.20.40, 1.20.50, 1.20.61, 1.20.71, 1.20.80, 1.21.0, 1.21.2, 1.21.21, 1.21.30, 1.21.42, 1.21.50, 1.21.60, 1.21.70, 1.21.80, 1.21.90, 1.21.93, 1.21.100`.
* **Протестировано на версиях:** `1.21.50`.

---

## Ключевые особенности

* **Контейнеры данных**: Готовые классы для хранения и модификации игровых данных (миры, серверы, игроки).
* **Автоматизация протокола**: Встроенное управление пакетами и процессами подключения «из коробки».
* **Эмуляция клиента**: Точное воспроизведение поведения реального игрового клиента на уровне сетевых пакетов.
* **Модульность**: Возможность замены стандартных классов на кастомные или расширение логики через наследование.

---

### Кастомный класс клиента

* **Контроль сессий**: Позволяет сохранять и загружать сессии, чтобы бот мог авторизоваться на сервере без повторного ввода данных.
* **Многоразовый клиент**: Позволяет отключаться и подключаться к серверу через один и тот же экземпляр класса, сохраняя статус сессии.
* **Гибкая настройка Login-пакета**: Свободная модификация данных при входе (скины, данные об устройстве и т.д.).

---

### 🛠 Текущие изменения (v0.5)
* **Адаптеры**: Возможность замены стандартной библиотеки обработки сетевых данных на собственную через систему адаптеров.
* **DataBase**: Классы хранилища в ядре теперь получают метаданные напрямую из классов протокола.
* **Plugins**: Теперь вы можете загружать свои собственные плагины прямо в базовый класс бота, смотрите [документацию](#документация)
* **Чистка кода**: Исправлены ошибки в тестах и проведена оптимизация.

## 🚀 Начало работы

Больше примеров и тестов можно найти в папке [tests](../../tests/).

```javascript
import { Bot, BotOptions } from 'minetoring'

// Удобная настройка через IDE
const opt = new BotOptions()
opt.configServer({
    version: '1.21.50',
    host: '127.0.0.1',
    port: 19132
})
opt.configClient({
    username: 'Steve'
})

const bot = new Bot()
// Асинхронная инициализация для загрузки модулей протокола
await bot.init(opt)

await bot.connect()
// Ожидание полной загрузки клиента и спавна
await bot.waitUntilSpawn()

// Быстрая отправка сообщения в чат
bot.actions.sendMessage('Hello World!')
await bot.disconnect()
```

## 🏗 Архитектура проекта

Проект разделен на логические блоки для удобства разработки:

* **Core — [BaseClasses](../../src/BaseClasses/)**: Фундамент системы. Содержит абстрактные классы для хранилищ данных и клиента.
* **Main — [MainClasses](../../src/MainClasses/)**: Основные модули автоматизации. Включает динамический импорт протоколов и главный класс бота.
