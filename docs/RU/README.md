**Продвинутый фреймворк**, построенный поверх библиотеки **Bedrock-Protocol**, предоставляющий высокоуровневый API для создания ботов в Minecraft Bedrock.


## Ключевые особенности

**MineToring** - это первый проект, который предоставляет **высокоуровневый API** для работы с ботами в **Minecraft Bedrock Edition**

---

- **Полностью нативный фреймворк для Minecraft Bedrock**: Спроектирован специально под особенности Bedrock-издания.
- **Поддержка сущностей (Entities)**: Бот видит всех сущностей и игроков в радиусе прорисовки и знает о них всю информацию от атрибутов до устройства, с которого играет пользователь.
- **Рабочая загрузка мира**: Полноценная нативная загрузка чанков мира с поддержкой blob и нулевой потерей данных.
- **Высокоуровневые действия**: Готовые действия бота, позволяющие автоматически возрождаться после смерти или отправлять команды в чат.
- **Поддержка EventEmitters**: Классы сущностей, игроки и многие другие компоненты имеют встроенную поддержку событий через метод `.events`. Это позволяет подписываться на обновления конкретной сущности, мира или высокоуровневого действия.
- **Автоматическое обновление**: Полностью автоматическое обновление всех сущностей, данных мира и многого другого. Вы всегда будете видеть максимально актуальные данные, присылаемые сервером.
- **Совместимость с PrismarineJs**: Для декодирования чанков можно использовать адаптер для библиотеки **Prismarine-Chunk**, который предоставляет готовые высокоуровневые методы для работы с данными из класса чанков MineToring.

---

* **Контейнеры данных**: Готовые классы для хранения и модификации игровых данных (миры, серверы, игроки).
* **Автоматизация протокола**: Встроенное управление пакетами и процессами подключения «из коробки».
* **Эмуляция клиента**: Точное воспроизведение поведения реального игрового клиента на уровне сетевых пакетов.
* **Модульность**: Возможность замены стандартных классов на кастомные или расширение логики через наследование.

---

* **Поддерживаемые версии Minecraft Bedrock:** `1.21.0, 1.21.2, 1.21.21, 1.21.30, 1.21.42, 1.21.50, 1.21.60, 1.21.70, 1.21.80, 1.21.90, 1.21.93, 1.21.100`.
* **Протестировано на версиях:** `1.21.0, 1.21.50, 1.21.100`.

## Начало работы

Больше примеров можно найти в папке [examples](/examples/).

```javascript
import { Bot, BotOptions } from 'minetoring'

// Для помощи и упрощенной настройки в IDE
const opt = new BotOptions()
opt.configServer({
    version: '1.21.50',
    host: '127.0.0.1',
    port: 19132
})
opt.configClient({
    username: 'Steve',
})

const bot = new Bot()
// Асинхронная инициализация для динамического импорта модулей протокола
await bot.init(opt)
await bot.connect()

// Необходимо для уверенности, что клиент загружен на момент отправки пакетов
await bot.waitUntilSpawn()

// await необязателен для действий, когда вам не нужно ждать обработки пакета сервером
await bot.actions.sendMessage('Hello World!')
bot.disconnect()
```
