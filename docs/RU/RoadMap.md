# MineToring - План разработки

Наша цель - создать стабильный, расширяемый и высокопроизводительный NodeJS клиент для **Minecraft Bedrock Edition**.

---

## Планы следующей версии (v1.0)

### 1. Расширенное взаимодействие с миром
* [x] **Система отслеживания сущностей**: Эффективное отслеживание в реальном времени и хранение метаданных мобов и игроков.
* [x] **Высокоуровневое API действий**: Расширить модуль Actions новыми действиями и добавить EventEmitter чтобы слушать высокоуровневые события (respawn, chat)
* [x] **Нативный декодер данных**: Встроенный, высокоэффективный и независимый от других библиотек декодер сетевых данных буферов чанков, подчанков и не только.
* [ ] **Инвентарь и предметы**: Высокоуровневое API для работы с инвентарями блоков, сущностей и предметов. Локальные и сетевые действия с интерфейсами инвентарей.
* [ ] **Новые события**: Новые высокоуровневые события на действия мобов и игроков внутри прогруженной области бота. К примеру: EntityHitEntity, EntityHit и подобные.

### 2. Развитие технической поддержки кода
* [ ] **Рефакторинг для мультиверсионности**: Найти рабочее решение, которое позволит проекту поддерживать множество разных версий игры прямо на лету.
* [x] **Полная документация**: Подробное справочное руководство по API на английском и русском языках.
* [ ] **Новые тесты**: Написать больше автоматизированных тестов.
* [x] **Примеры**: Отдельная папка для примеров кода.

## Будущие цели (После v1.0)

### Физика и навигация
* **Физический движок**: Разработка нативного движка для обработки, просчёта и симуляции физики передвижения для игроков и сущностей.
* **Научить бота ходить**: Создать базовое API для передвижения по миру.
* **Продвинутый поиск пути**: Внедрение алгоритма A* или аналогичных решений, интегрированных с физическим движком и API перемещения.

### Взаимодействие с миром
* **Базовое взаимодействие**: Высокоуровневое API для базового инпута игрока, использование ПКМ и ЛКМ для блоков и предметов имитируя выходные данные официального клиента.
* **Сражение и добыча**: Возможность атаковать мобов и игроков, добывать, ставить и взаимодействовать с блоками.

### Оптимизация
* **Расширение охвата протокола**: Поддержка и оперативное обновление для новых и старых версий протокола Bedrock по возможности поддержки.
