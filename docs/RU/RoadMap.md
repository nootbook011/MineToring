# MineToring - План разработки

Наша цель — создать самый стабильный, расширяемый и высокопроизводительный клиент для Minecraft Bedrock, работающий на уровне пакетов.

---

## Планы следующей версии (v1.0)

### 1. Расширенное взаимодействие с миром
* [ ] **Система отслеживания сущностей**: Эффективное отслеживание в реальном времени и хранение метаданных мобов и игроков.
* [ ] **Высокоуровневое API дейтсвий**: Расширить модуль Actions новыми дейтсвиями и добавить EventEmitter чтобы слушать высокоуровневые события (health, respawn, chat)
* [ ] **Стабильное публичное API**: Финализация структуры классов `Core` и `Main` для обеспечения долгосрочной совместимости.

### 2. Развитие технической поддержки кода
* [ ] **Полная документация**: Подробное справочное руководство по API на английском и русском языках.
* [ ] **Новые тесты**: Написать больше автоматизированных тестов.
* [ ] **Примеры**: Отдельная папка для примеров кода.

---

## Будущие цели (После v1.0)

### Физика и навигация
* **Физический движок**: Разработка нативного движка коллизий для геометрии блоков Bedrock.
* **Научить бота ходить**: Создать базовую систему для передвижения по миру.
* **Продвинутый поиск пути**: Внедрение алгоритма A* или аналогичных решений, интегрированных с физическим движком.

### Низкоуровневые оптимизации
* **Кастомный декодер полезной нагрузки (Payload Decoder)**: Легковесный движок для высокоскоростного декодирования данных чанков и суб-чанков.
* **Расширение охвата протокола**: Поддержка и оперативное обновление для новейших версий протокола Bedrock.
