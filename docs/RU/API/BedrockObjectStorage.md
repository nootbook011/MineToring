# Class: BedrockObjectStorage

Базовый класс для организации хранения данных игровых объектов. Он используется как фундамент для чанков и подчанков, обеспечивая единообразный интерфейс доступа к состоянию объекта и его метаданным.

## Структура хранилища

Каждый объект, наследующий `BedrockObjectStorage`, имеет внутреннюю структуру, разделенную на три части:
1. **Metadata**: Описательные данные (координаты, ключи кэша и т.д.).
2. **Data Raw**: "Сырые" данные, полученные напрямую из сетевых пакетов или базы данных.
3. **Data Decoded**: Обработанные данные (например, объекты `prismarine-chunk`), готовые к использованию в логике бота.

---

## Свойства

### `metadata`
Возвращает объект метаданных хранилища.

### `data`
Возвращает объект, содержащий два вложенных объекта: `raw` и `decoded`.

### `static base` (геттер)
Статическое свойство, возвращающее шаблон пустой структуры хранилища.

## Методы обновления данных

### `constructor(metadata? = undefined, data? = undefined)`
Создает экземпляр хранилища. Если переданы аргументы, они автоматически применяются через соответствующие методы установки.

### `setMetadata(metadataInput)`
Рекурсивно обновляет текущие метаданные.
* **metadataInput**: Объект с новыми ключами и значениями. Существующие ключи, не затронутые обновлением, сохраняются.

### `setData(rawDataInput)`
Устанавливает новые "сырые" данные и **полностью сбрасывает** текущие декодированные данные. Это гарантирует, что при обновлении сетевого пакета старая (неактуальная) интерпретация данных будет удалена.
* **rawDataInput**: Объект с новыми сырыми данными.

### `_setDataDecoded(decodedDataInput)`
Внутренний метод (предназначен для адаптеров) для записи результатов парсинга. В отличие от `setData`, этот метод не сбрасывает другие поля, а дополняет объект `decoded`.

---

## Технические детали

Класс использует вспомогательную функцию `recurseUpdate`, что позволяет выполнять глубокое обновление объектов. Это удобно, когда нужно обновить только одно поле в сложном объекте метаданных, не перезаписывая весь объект целиком.
