# Class: BedrockPlayer наследует [BedrockEntity](./BedrockEntity.md)

Класс, представляющий игрока в мире Minecraft Bedrock. Дополняет родительский класс функционалом для управления способностями игрока.

## Содержание
- [Свойства](#свойства)
- [Методы](#методы)

---

## Свойства

### `abilities`
Геттер, возвращающий объект с текущими способностями игрока. Сюда входят параметры разрешений (permissions), возможности полета, строительства, атаки и другие флаги, передаваемые сервером.

### `dimension`
Свойство которое есть только у экземпляра класса принадлежащему боту. Оно показывает в каком измерении находится  бот в данный момент и из этого измерения идет актуальный поток информации, содержит dimensionId.

---

## Методы

### `setAbilities(abilitiesInput)`
Обновляет способности игрока. Использует глубокое обновление (`recurseUpdate`), что позволяет изменять отдельные флаги, не перезаписывая весь объект способностей.
* **abilitiesInput**: Объект с новыми значениями способностей.
