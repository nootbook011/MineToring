# Class: BedrockPlayer наследует [BedrockEntity](./BedrockEntity.md)

Класс, представляющий игрока в мире и сервере.

## Содержание
- [Свойства](#свойства)
- [События](#события)
- [Методы](#методы)

---

## Свойства

### `metadata`
**Тип**: `Object`

Объект с динамическими метаданными игрока.
Содержимое зависит от версии протокола который использует мир, [смотрите ProtocolAPI.](./Versions/protocolAPI.md)

### `abilities`
**Тип**: `Object`

Объект с динамическими способностями игрока.

## Динамические Свойства

### `skin`
**Тип**: `BedrockSkin`

Предоставляет доступ к хранилищу данных о скине игрока.

* **Добавляет**: `BedrockSkin`

### `dimension`
**Тип**: `Number(dimensionId)`

Свойство которое есть только у экземпляра класса принадлежащему боту. Оно показывает в каком измерении находится  бот в данный момент и из этого измерения идет актуальный поток информации.

* **Добавляет**: `ClientPacketSession`

---

## События

### `changeGamemode(gamemode)`
Вызывается при изменении режима игры игрока.

**Параметры**:
- `gamemode` (`Number(gamemodeId)`): Текущий режим игры.

### `changeDimesion(dimension)`
Вызывается при изменении измерения игрока.

**Параметры**:
- `dimension` (`Number(dimensionId)`): Текущее измерение.

---

## Методы

### `setAbilities(abilitiesInput)`
Глубокое обновление способностей.

**Параметры**:
- `abilitiesInput` (`Object`): Объект с обновленными знаниями.
