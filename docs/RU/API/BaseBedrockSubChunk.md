# Class: BedrockSubChunk наследует [BedrockObjectStorage](./BedrockObjectStorage.md)

Класс для управления данными подчанка (секции чанка). Он является частью структуры `BedrockChunk` и предоставляет доступ к данным конкретного вертикального слоя блоков.

## Свойства

### `hasPayload`
Булево значение, указывающее на наличие полезной нагрузки в подчанке.

### `DSubChunk`
Геттер для получения декодированного объекта подчанка. 
* **Примечание**: Данные в этом свойстве появляются только после того, как родительский чанк был обработан методом `decodeChunkWithAdapter`.

---

## Внутренние методы

### `_setDecodeSubChunk(decodeSubChunk)`
Внутренний метод, используемый адаптерами для сохранения декодированных данных секции.
* **decodeSubChunk**: Объект с обработанными данными блоков и палитр.

---

## Связь с декодированными данными

`BedrockSubChunk` работает в связке с `BedrockChunk`. Когда вызывается декодирование всего чанка, данные распределяются по соответствующим подчанкам:

1. Родительский `BedrockChunk` хранит `BedrockSubChunk`.
2. Адаптер (например, Prismarine) преобразует их в декодированые классы.
3. Метод `_setDecodeSubChunk` записывает результат в соответствующий экземпляр `BedrockSubChunk`.
