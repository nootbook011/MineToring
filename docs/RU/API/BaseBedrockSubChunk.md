# Class: BedrockSubChunk наследует [BedrockObjectStorage](./BedrockObjectStorage.md)

Класс для управления данными подчанка (секции чанка). Он является частью структуры `BedrockChunk` и предоставляет доступ к данным конкретного вертикального слоя блоков.

- [Методы](#методы)

---

## Свойства

### `position`
**Тип**: `V3{ x, y, z }`

Быстрый доступ к позиции блока.

### `metadata`
**Тип**: `Object`

Объект с динамическими метаданными подчанка.
Содержимое зависит от версии протокола который использует мир, [смотрите ProtocolAPI.](./Versions/protocolAPI.md)

### `hasPayload`
**Тип**: `Boolean`

Показывает на наличие полезной нагрузки в подчанке.

### `blocks`
**Тип**: `Array<BedrockBlocksStorage>`

Возвращает массив слоев, каждый слой содержит хранилище всех блоков на нем. Обычно подчанк имеет всего два слоя: 0 - основной слой блоков, 1 - содержит только блоки, которые могут быть внутри других блоков, например вода или снег, которые могут быть залиты внутри забора или листвы.

### `pallete`
**Тип**: `Array< Array<Number> >`

Возвращает массив слоев, каждый слой содержит палитру, которая содержит runtimeId всех игровых блоков, которые есть в хранилище чанка. Блоки внутри `BedrockBlocksStorage` ссылаются на индексы этого массива для их определения.

## Методы

### `setPayload(payload)`
Если подчанк был создан через метод парсера протокола или класс `BedrockDimension`, то метод автоматически декодирует буффер данных из пакета subChunk в соответствии с версией протокола и заполняет собственный класс данными. В остальных случаях этот метод ничего не делает и является заглушкой.

**Параметры**:
- `payload` (`Array|Buffer`): Полезная нагрузка подчанка из пакета SubChunk

### `getLayer(layer)`
Возвращает объект с данными массивов blocks и pallete для конкретного слоя.

**Параметры**:
- `layer` (`Number`): Слой данных.

**Возвращает**: `{ blocks: BedrockBlocksStorage, palette: Array<Number> }`

### `setLayer(layer, blocks, palette)`
Устанавливает данные палитры.

**Параметры**:
- `layer` (`Number`): Слой данных.
- `blocks` (`BedrockBlocksStorage`): Данные блоков для слоя.
- `palette` (`Array<Number>`): Данные палитры для слоя.

### `getBlockEntity(x, y, z)`
Возвращает данные EntityNbt для конкретного блока в подчанке.

**Параметры**:
- `x` (`number`): Локальная координата X блока в подчанке.
- `y` (`number`): Локальная координата Y блока в подчанке.
- `z` (`number`): Локальная координата Z блока в подчанке.

**Возвращает**: `Object `

### `setBlockEntity(x, y, z, data)`
Устанавливает данные EntityNbt для конкретного блока в подчанке.

**Параметры**:
- `x` (`number`): Локальная координата X блока в подчанке.
- `y` (`number`): Локальная координата Y блока в подчанке.
- `z` (`number`): Локальная координата Z блока в подчанке.
- `data` (`Object`): Данные EntityNbt для блока.

### `getBlockId(x, y, z, l)`
Возвращает runtimeId блока на конкретном слое подчанка.

**Параметры**:
- `x` (`number`): Локальная координата X блока в подчанке.
- `y` (`number`): Локальная координата Y блока в подчанке.
- `z` (`number`): Локальная координата Z блока в подчанке.
- `l` (`number`): Слой целевого блока.

**Возвращает**: `Number`

### `setBlockId(x, y, z, l, id)`
Устанавливает runtimeId блока на конкретном слое подчанка.

**Параметры**:
- `x` (`number`): Локальная координата X блока в подчанке.
- `y` (`number`): Локальная координата Y блока в подчанке.
- `z` (`number`): Локальная координата Z блока в подчанке.
- `l` (`number`): Слой целевого блока. 
- `id` (`number`): Новый runtimeId блока.
