# Class: BedrockSubChunk наследует [BedrockObjectStorage](./BedrockObjectStorage.md)

Класс для управления данными подчанка (секции чанка). Он является частью структуры `BedrockChunk` и предоставляет доступ к данным конкретного вертикального слоя блоков.

## Содержание
- [Свойства](#свойства)
- [Методы](#методы)

---

## Свойства

### `hasPayload`
**Тип**: `Boolean`

Показывает на наличие полезной нагрузки в подчанке.

### `DSubChunk`
**Тип**: `DecodedSubChunk|undefined`

Возвращает декодированный объект подчанка если был вызван `.decodeChunkWithAdapter()` на родительском чанке, иначе `undefined`.

---

## Методы

### `_setDecodeSubChunk(decodeSubChunk)`
Внутренний метод, используемый адаптерами для сохранения декодированных данных секции.

**Параметры**:
- `decodeSubChunk` (`DecodedSubChunk`): Объект с обработанными данными блоков и палитр.
