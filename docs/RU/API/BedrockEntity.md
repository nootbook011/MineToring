## Свойства

### `metadata`
**Тип**: `Object`

Объект с динамическими метаданными сущности.
Содержимое зависит от версии протокола который использует мир, [смотрите ProtocolAPI.](./Versions/protocolAPI.md)

### `states`
**Тип**: `Object`

Текущие состояния и переменные сущности.

### `events`
**Тип**: `EventEmitter`

Дает доступ к классу EventEmitter сущности.

## Динамические Свойства

### `attributes`
**Тип**: `BedrockAttributes`

Дает доступ к контроллеру атрибутов сущности. Он может получать/изменять конкретные атрибуты по их названиям.

* **Добавляет**: `BedrockAttributes`

### `health`
**Тип**: `Number|undefined`

Быстрый доступ к здоровью сущности.

* **Добавляет**: `BedrockAttributes`

### `food`
**Тип**: `Number|undefined`

Быстрый доступ к голоду сущности.

* **Добавляет**: `BedrockAttributes`

### `xp`
**Тип**: `Number|undefined`

Быстрый доступ к уровню сущности.

* **Добавляет**: `BedrockAttributes`

### `physics`
**Тип**: `BedrockPhysicsManager`

Дает доступ к контроллеру физических состояний сущности. Не рекомендуется  изменять в нем какие-либо значения.

* **Добавляет**: плагин `BedrockPhysicsManager`

### `position`
**Тип**: `V3{ x, y, z }`

Быстрый доступ к позиции сущности.

* **Добавляет**: плагин `BedrockPhysicsManager`

### `rotation`
**Тип**: `{ pitch, yaw: { all, body, head }`

Быстрый доступ к повороту сущности.

* **Добавляет**: плагин `BedrockPhysicsManager`

## События

### `attributes(new, old)`
Вызывается при обновлении атрибутов сущности.

**Параметры**:
- `new` (`Object`): актуальные атрибуты.
- `old` (`Object|undefined`): устаревшие атрибуты.

### `states(new)`
Вызывается при обновлении состояний сущности.

**Параметры**:
- `new` (`Object`): актуальные состояния.

### `move(position, rotation)`
Вызывается при обновлении позиции и поворота сущности.

**Параметры**:
- `position` (`V3{ x, y, z }`): Новая позиция сущности.
- `rotation` (`{ pitch, yaw: { all, body, head }`): Новый поворот сущности.

### `despawn`
Вызывается при деспавне сущности (Пропаже из зоны видимости бота), этот метод означает либо смерть сущности либо выход из дистанции прорисовки бота. В любом из исходов данный класс сущности считается устаревшим и не будет обновляться после вызова этого события.

**Значения**: 
- **Смерть**:Сущность больше не появится и не будет обновляться. Для точного определения желательно использовать событие `death`.
- **Выход из дистанции прорисовки**: Сущность с такими же данными может появиться снова с новым классом сущности.

### `death`
Вызывается после игровой смерти сущности в мире. После вызова этого события данный класс сущности считается устаревшим и не будет обновляться после вызова этого события.

- `statesInput` (`Object`): Объект с обновленными знаниями.

## Плагины зависимости
В класс загружаются базовые плагины для корректной работы.
* **BedrockAttributes**: Менеджер характеристик сущности (здоровье, голод, скорость передвижения и т.д.).
* **BedrockPhysicsManager**: Отвечает за пространственные и физические данные сущности: координаты, углы поворота и хитбоксы.

Документацию по классам плагинов смотрите в [этом файле.](./Versions/protocolAPI.md)
