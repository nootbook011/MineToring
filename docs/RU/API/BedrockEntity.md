## Свойства
* **`metadata`**: Объект с метаданными сущности (ID, тип и т.д.).
* **`states`**: Текущие состояния сущности.
* **`events`**: Экземпляр `EventEmitter` для прослушивания изменений конкретной сущности.

---

## События
* **attributes(new, old)**: Вызывается при обновлении атрибутов сущности. new - актуальные атрибуты, old - устаревшие атрибуты.
* **states(new)**: Вызывается при обновлении состояний сущности, new - актуальные состояния.
* **move(position, rotation)**: Вызывается при обновлении позиции и поворота сущности.
* **despawn**: Вызывается при деспавне сущности (удалении из измерения), этот метод означает либо смерть сущности либо выход из зоны видимости игрока. В любом случае после вызова этого метода данный класс считается неактуальным и информация из него больше не будет обновляться.

---

## Методы
* **`setMetadata(metadataInput)`**: Глубокое обновление метаданных.
* **`setStates(statesInput)`**: Глубокое обновление состояний.

---

## Плагины зависимости
В класс автоматически загружаются базовые плагины для корректной работы.
* **BedrockAttributes**: Менеджер характеристик сущности (здоровье, голод, скорость передвижения и т.д.).
* **BedrockPhysicsManager**: Отвечает за пространственные и физические данные сущности: координаты, углы поворота и хитбоксы.

Документацию по классам плагинов смотрите в [этом файле.](./Versions/protocolAPI.md)
