# Class: BedrockDimension наследует [BedrockPlugins](./BedrockPlugins.md)

Класс представляет собой контейнер для данных конкретного игрового измерения (Overworld, Nether, End). Он управляет сеткой загруженных чанков и предоставляет API для добавления, получения и валидации игровых данных.

## Свойства

### `id`
**Тип**: `number`

Возвращает `dimensionId` целевого измерения.

### `events`
**Тип**: `EventEmitter`

Предоставляет доступ к классу `EventEmitter` измерения.

### `chunks`
**Тип**: `BedrockMap`

Возвращает экземпляр `BedrockMap`, содержащий все загруженные чанки в этом измерении. Позволяет получить прямой доступ к чанкам по координатам.

### `length`
**Тип**: `number`

Возвращает общее количество загруженных чанков в измерении.

## События

### `chunkLoaded(chunk)`
Вызывается, когда обработчик запросил у сервера все подчанки этого чанка. Важно: событие вызывается именно в момент запроса, а не в момент получения данных, из-за сложности в реализации. Поэтому сами данные подчанков приходят с задержкой после вызова.

**Параметры**:
- `chunk` ([`BedrockChunk`](./BedrockChunk.md)): Данные загруженного чанка.

## Методы

### `create(dimensionId? = undefined)`
Инициализирует `dimensionId` измерения. Перед вызовом обязательно нужно инициализировать зависимости методом `.init` или передать их в конструкторе, иначе выбросит исключение.

**Параметры**:
- `dimensionId` (`number`): ID целевого измерения.

**Выбрасывает**: 
- `TypeError`: Если зависимости не определены методом `.init`.

### `addChunk(chunkPacket)`
Парсит и добавляет полный чанк в карту измерения.

**Параметры**:
- `chunkPacket` (`Object`): Пакет `level_chunk` от сервера.

**Возвращает**: [`BedrockChunk`](./BedrockChunk.md)

### `addSubChunks(subChunkPacket)`
Добавляет данные подчанков в измерение.

**Параметры**:
- `subChunkPacket` (`Object`): Пакет `subchunk` от сервера.

### `getChunk(x, z)`
Возвращает объект чанка по его координатам без парсинга или модификации.

**Параметры**:
- `x` (`number`): Координата X чанка.
- `z` (`number`): Координата Z чанка.

**Возвращает**: [`BedrockChunk`](./BedrockChunk.md)|`undefined`

### `getBlock(x, y, z)`
Возвращает полные данные конкретного блока в измерении.

**Параметры**:
- `x` (`number`): Координата X блока.
- `y` (`number`): Координата Y блока.
- `z` (`number`): Координата Z блока.

**Выбрасывает**:
- `ChunkAccessError` — Выбрасывается, когда чанк или подчанк, в котором находится блок, не загружен или повреждён.

**Возвращает**: [`BedrockBlock`](./BedrockBlock.md)


### `setBlock(block, x, y, z)`
Устанавливает данные из класса [`BedrockBlock`](./BedrockBlock.md) по указанным координатам в мире.

> [!WARNING]
> Метод изменяет данные только в локальном хранилище и не передаёт изменения на сервер!

**Параметры**:
- `block` (`BedrockBlock`): Целевой класс блока.
- `x` (`number`): Координата X блока.
- `y` (`number`): Координата Y блока.
- `z` (`number`): Координата Z блока.

**Выбрасывает**:
- `ChunkAccessError` — Выбрасывается, когда чанк или подчанк, в котором находится блок, не загружен или повреждён.

**Возвращает**: `boolean`


### `getBiome(x, y, z)`
Возвращает данные биома по конкретным координатам в измерении.

**Параметры**:
- `x` (`number`): Координата X.
- `y` (`number`): Координата Y.
- `z` (`number`): Координата Z.

**Выбрасывает**:
- `ChunkAccessError` — Выбрасывается, когда чанк или подчанк, в котором находится блок, не загружен или повреждён.

**Возвращает**: `MinecraftData.Biome` — Данные целевого биома из `minecraft-data`.


### `getBlocks(from, to)`
Возвращает итератор, который проходит по всем координатам в заданном диапазоне и возвращает полные данные каждого блока.
Координаты можно передавать в любом порядке — функция автоматически найдёт самые нижние и самые верхние.

**Параметры**:
- `from` (`V3{ x, y, z }`): Объект `V3` с координатами начального угла.
- `to` (`V3{ x, y, z }`): Объект `V3` с координатами конечного угла.

**Возвращает**: `BlocksAreaIterator<`[`BedrockBlock`](./BedrockBlock.md)`>`

### `findBlocks(callBack, from, to)`
Высокоэффективный алгоритм поиска блоков в диапазоне мировых координат. Принимает callback-функцию, в которую передаёт статические данные каждого блока в игре из `minecraft-data`. Функция должна вернуть `true` для тех данных блоков, которые соответствуют требованиям поиска.
Координаты можно передавать в любом порядке - функция автоматически найдёт самые нижние и самые верхние.

**Параметры**:
- `callback` (`(blockMetadata) => Boolean`): Функция, принимающая статические метаданные блока из `minecraft-data` и возвращающая `true`, если блок соответствует требованиям поиска, и `false`/`undefined`, если нет. 
- `from` (`V3{ x, y, z }`): Объект `V3` с мировыми координатами начального угла.
- `to` (`V3{ x, y, z }`): Объект `V3` с мировыми координатами конечного угла.

**Возвращает**: `BlocksIterator<`[`BedrockBlock`](./BedrockBlock.md)`>`

### `_clear()`
Полностью очищает карту чанков.
