# Class: BedrockDimension наследует [BedrockPlugins](./BedrockPlugins.md)

Класс представляет собой контейнер для данных конкретного игрового измерения (Overworld, Nether, End). Он управляет сеткой загруженных чанков и предоставляет API для добавления, получения и валидации игровых данных.

## Свойства

### `events`
**Тип**: `EventEmitter`

Дает доступ к классу EventEmitter измерения.

### `chunks`
**Тип**: `BedrockMap`

Возвращает экземпляр `BedrockMap`, содержащий все загруженные чанки в этом измерении. Позволяет прямой доступ к чанкам по координатам.

### `length`
**Тип**: `number`

Возвращает общее количество загруженных чанков в измерении.

## События

### `chunkLoaded(chunk)`
Вызывается когда обработчик запросил у сервера все подчанки этого чанка. Важно что событие вызывается именно в момент запрос а не в момент получения данных из за сложности в реализации. Так что сами данные подчанков приходят с задержкой после вызова.

**Параметры**:
- `chunk` ([`BedrockChunk`](./BaseBedrockChunk.md)): Данные загруженого чанка.

## Методы

### `constructor(plugins = {})`
Создает экземпляр измерения.

**Параметры**:
- `plugins` (`Object`): Объект с плагинами.

### `async initProtocol(protocol? = undefined)`
Инициализирует данные протокола класса, не рекомендуется вызывать самостоятельно, если вы не знаете, что делаете.

**Параметры**:
- `protocol` (`BedrockProtocol|undefined`): Если установлен уже имеющийся протокол, то он будет инициализирован в классе, в противном случае асинхронно инициализирует протокол автоматически, опираясь на свойство `.version` класса.

### `add(packets)`
Универсальный метод для добавления данных о мире за один вызов.

**Параметры**:
- `packets` (`Object`): Объект с пакетами
  - `chunk` (`Object`): Пакет `level_chunk` (опционально)
  - `subChunks` (`Object`): Пакет `subchunk` (опционально)

### `addChunk(levelChunkPacket)`
Парсит и добавляет полный чанк в карту измерения.

**Параметры**:
- `levelChunkPacket` (`Object`): Пакет `level_chunk` от сервера

**Возвращает**: [`BedrockChunk`](./BaseBedrockChunk.md)

### `addSubChunks(subChunkPacket)`
Добавляет данные подчанков в измерение.

**Параметры**:
- `subChunkPacket` (`Object`): Пакет `subchunk` от сервера

### `getChunk(x, z)`
Возвращает объект чанка по его координатам без парсинга или модификации.

**Параметры**:
- `x` (`number`): Координата X чанка
- `z` (`number`): Координата Z чанка

**Возвращает**: [`BedrockChunk`](./BaseBedrockChunk.md)|`undefined`

### `async validateChunk(x, z)`
Выполняет полную валидацию и декодирование чанка с использованием адаптера данных загруженого как плагин `.ValidateAdapter`.

**Параметры**:
- `x` (`number`): Координата X чанка
- `z` (`number`): Координата Z чанка

**Возвращает**: Promise<[`BedrockChunk`](./BaseBedrockChunk.md)|`false`>

### `_clear()`
Полностью очищает карту чанков.

## Плагины-зависимости

* **ValidateAdapter** (Опционально): Адаптер для декодирования чанков (обычно `PrismarineAdapter` если измерение автоматически инициализировал [`BedrockWorld`](./BaseBedrockWorld.md)).
* **BlobsManager** (Опционально): Менеджер кэширования чанков.
