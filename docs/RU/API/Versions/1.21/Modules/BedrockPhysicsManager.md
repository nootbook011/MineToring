# Class: BedrockPhysicsManager

Отвечает за пространственные данные сущности: координаты, углы поворота и хитбоксы.

## Внедренные свойства
При инициализации менеджер добавляет в объект `entity` следующие геттеры/сеттеры:
* **`entity.position`**: Вектор текущей позиции.
* **`entity.rotation`**: Объект с углами поворота (pitch, yaw).

## Структура данных
* **`location`**: Хранит позицию и три вида `yaw` (общее, тело, голова) + `pitch`.
* **`physics`**: Скорость (velocity).
* **`collision`**: Хитбоксы, bounding box и масштаб (scale).

## Методы
* **`setRotation(pitch, yaw)`**: Обновляет углы поворота. `yaw` может принимать объект `{ all, body, head }`.
