# Class: BedrockAttributes

Менеджер характеристик сущности (здоровье, голод, скорость передвижения и т.д.). 

## Особенности
* **Proxy-доступ**: Позволяет обращаться к атрибутам напрямую через `entity.attributes.health` вместо вызова методов.
* **Авто-префикс**: Автоматически добавляет префикс `minecraft:`, если он отсутствует.
* **Валидация**: При установке значения (`set`) проверяет границы `min` и `max`.
* **Доступ к Map**: Дает доступ ко всем методам объекта Map в котором хранятся атрибуты.

## Методы
* **`get(name)`**: Получить значение атрибута.
* **`set(name, value)`**: Установить значение с учетом лимитов.
* **`object`**: Геттер, возвращающий чистый объект со всеми атрибутами (без префиксов).
