# Class: ActionsModule наследует BaseModule

Класс `ActionsModule` предоставляет высокоуровневый интерфейс для взаимодействия бота с игровым миром Minecraft Bedrock. Он выполняет высокоуровневые пакетные действия.

## Свойства

### `events`
**Тип**: `EventEmitter`

Предоставляет доступ к внутреннему экземпляру `EventEmitter` для управления событиями модуля.

## Методы

### `async sendMessage(messageText, autoCommandExecute = true)`
Отправляет текстовое сообщение в чат. Если текст начинается с `/` и параметр `autoCommandExecute` включен, метод автоматически перенаправит вызов в `sendCommand`.

**Параметры**:
- `messageText` (`string`): Текст сообщения.
- `autoCommandExecute` (`boolean`): Если `true`, строки, начинающиеся с `/`, обрабатываются как команды. По умолчанию `true`.

### `async sendCommand(commandText, returnOutput = true)`
Отправляет команду на сервер.

**Параметры**:
- `commandText` (`string`): Текст команды (может включать или не включать префикс `/`).
- `returnOutput` (`boolean`): Если `true`, метод дождется ответа от сервера и вернет результат выполнения. По умолчанию `true`.

**Возвращает**: `Promise<Object|undefined>` — Объект вывода команды (поле `output` из пакета) или `undefined`.

### `respawn()`
Инициирует процесс возрождения игрока. Метод отправляет необходимые пакеты серверу.

### `on(e, cb)` / `once(e, cb)` / `off(e, cb)`
Вспомогательные методы для управления событиями модуля (проксируют вызовы к `this.events`).

**Параметры**:
- `e` (`string`): Название события.
- `cb` (`function`): Функция обратного вызова.

## События

### `text(textData)`
Вызывается при получении сообщения ботом.

**Параметры**:
- `textData` (`Object`): Объект с данными. Структура данных показана снизу.

**TextData**
```js
{
    type: String,
    from: {
        name: String|undefined,
        xuid: String|undefined,
        },
    text: String,
}
```
