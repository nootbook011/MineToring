# Class ActionsModule

Высокоуровневый класс для вызова высокоуровневых действий или подписки на события, пример: `actions.on('chat', (data) => actions.sendMessage(data.text) )`.

- [События](#события)

---

## Свойства
* **`events`**: Геттер, возвращающий экземпляр EventEmitter класса.

## Методы
### `on`, `once`, `off` (eventName, callBack)
Прокси методы для доступа к методам EventEmitter класса.

### async `SendMessage` (messageText, autoCommandExecute? = true)
Отправляет сообщение пакетом `text` на сервер. Так же ждать разрешения промиса этого метода необязательно если вам не нужно ждать пока пакет будет обработан сервером.
* **`messageText`**: Текст сообщения.
* **`autoCommandExecute`**: Если true, то автоматически вызывает `sendCommand` для любых сообщений, начинающихся с **'/'**, при этом возвращая результат выполнения команды.
