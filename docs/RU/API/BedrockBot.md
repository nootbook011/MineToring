# Class: BedrockBot наследует [BaseBedrockBot](./BaseBedrockBot.md)

Высокоуровневый класс для создания полнофункционального бота в Minecraft Bedrock Edition. Он объединяет управление сетевым протоколом, автоматическое хранение и синхронизацию данных о мире, сервере и игроке, а также встроенный модуль действий для выполнения команд.

## Свойства

### `world`
**Тип**: `BedrockWorld`

Экземпляр класса `BedrockWorld`, содержащий информацию о всех загруженных чанках, блоках и сущностях в зоне видимости бота. Инициализируется в методе `init()` после вызова родительского класса.

**Использует**:
- `PrismarineAdapter`: Для преобразования данных Bedrock протокола в удобный формат
- `BedrockBlobsManager`: Для кэширования (если включено в `options.client.settings.cache`)

### `server`
**Тип**: `BedrockServer`

Экземпляр класса `BedrockServer`, содержащий метаданные о текущем сервере: список игроков, время суток, погоду и другие глобальные параметры. Инициализируется одновременно с `world`.

### `actions`
**Тип**: `ActionsBotModule`

Геттер для доступа к модулю действий (загруженного как плагин). Позволяет выполнять высокоуровневые команды для взаимодействия с миром (например, `sendMessage`, `sendChat` и т.д.).

Пример доступа:
```javascript
if (bot.actions) {
    await bot.actions.sendMessage('Hello, world!')
}
```

### `workDir`
**Тип**: `string | undefined`

Путь к рабочей директории бота. Используется для сохранения логов (если `config.logging.logToFile` включено) и кэширования данных мира. Инициализируется из `options.config.botDir`.

## Методы

### `async init(options, plugins = {})`
Инициализирует бота высокого уровня. Расширяет метод родителя `BaseBedrockBot.init()` дополнительным функционалом.

**Параметры**:
- `options` (`BotOptionsManager | Object`): Конфигурация бота, должна содержать:
  - `config.botDir`: Путь к рабочей директории
  - `config.logging`: Настройки логирования
  - `client.settings.cache`: Включить ли кэширование чанков
- `plugins` (`Object`): Кастомные плагины и их зависимости

**Процесс инициализации**:
1. Вызывает `super.init()` для инициализации базового класса
2. Вызывает `#setupConfig()` для настройки логгера
3. Вызывает `#initStorage()` для создания World и Server
4. Вызывает `#initModules()` для загрузки ActionsBotModule

**Примечание**: Логгер переопределяется в этом методе согласно настройкам из `config`.

### `async connect()`
Переопределяет метод базового класса для добавления автоматической инициализации хранилищ данных.

**Дополнительный функционал**:
1. Инициализирует ClientPacketSession через `packetClient.init()`
2. Вызывает `super.connect()` для подключения к серверу
3. Запускает `packetClient.playerSimulationLoop()` для автоматической синхронизации данных игрока

## Архитектура и компоненты

### World (Мир)
Управляет всеми блоками, чанками и сущностями в загруженной области. Использует следующие адаптеры:
- **ValidateAdapter** (PrismarineAdapter): Преобразует пакеты Bedrock в стандартизированный формат
- **BlobsManager** (опционально): Кэширует чанки на диск для ускорения повторных загрузок

### Server (Сервер)
Хранит глобальное состояние сервера: время суток, погода, список игроков и другие метаданные.

### Actions (Действия)
Встроенный модуль для выполнения команд и взаимодействия с сервером:
- Отправка сообщений
- Выполнение команд
- Изменение состояния игрока

## Система логирования

### Инициализация логгера
Логгер инициализируется в методе `#setupConfig()` с параметрами из `options.config`:

```javascript
const logger = new Logger(
    level,                    // Уровень логирования из options.config.logging
    undefined,
    logToFile && botDir       // Путь к логам, если включено
)
```

### Параметры логирования
- `level`: Уровень детальности (0 = максимум, выше = меньше)
- `logToFile`: Сохранять ли логи на диск
- `botDir`: Директория для сохранения логов

## Примеры использования

### Полный цикл инициализации и подключения
```javascript
import { Bot, BotOptions } from 'minetoring'

const bot = new Bot()

const options = {
    server: {
        host: 'localhost',
        port: 19132,
        version: '1.21.50'
    },
    client: {
        username: 'TestBot',
        settings: {
            cache: true // Включить кэширование чанков
        }
    },
    config: {
        botDir: './bot_data',
        logging: {
            level: 1,
            logToFile: true
        }
    },
    network: {
        pingBeforeConnect: true
    }
}

await bot.init(options)
await bot.connect()
await bot.waitUntilSpawn()

console.log(`Бот заспавнился в точке: ${bot.player.position}`)
console.log(`Мир содержит ${bot.world.length} загруженных чанков`)
```

### Работа с World (миром)
```javascript
// Получить размер загруженной области
console.log(`Загруженных чанков: ${bot.world.length}`)

// Получить размер World
const dims = bot.world.getDimensions()
for (const dim of dims) {
    console.log(`Измерение ${dim.id}: ${dim.length} чанков`)
}

// Получить информацию о сервере
const time = bot.server.time
const players = bot.server.players
console.log(`Время на сервере: ${time.day} день, ${time.time}`)
console.log(`Игроков онлайн: ${players.length}`)
```

### Использование Actions (действий)
```javascript
if (bot.actions) {
    // Отправить сообщение в чат
    await bot.actions.sendMessage('Привет, мир!')
    
    // Другие доступные команды зависят от ActionsBotModule
    // для текущей версии протокола
}
```

### Работа с логами
```javascript
// Логи автоматически сохраняются в bot_data/logs
// если botDir и logToFile включены в конфигурации

// Можно использовать логгер напрямую через плагины
const logger = bot.plugins.Logger
logger.createLog('custom', 'Мой кастомный лог', 0)
```

## Заметки об изменениях

### История обновлений

**Версия 0.6.1**:
- Переработан метод `init()` для автоматической инициализации логгера из конфигурации
- Добавлена поддержка `options.config.logging` и `options.config.botDir`
- Метод `connect()` теперь автоматически инициализирует ClientPacketSession
- Добавлен `playerSimulationLoop()` для автоматической синхронизации данных игрока

### Отличия от BaseBedrockBot
| Функция | BaseBedrockBot | BedrockBot |
| :--- | :--- | :--- |
| World инициализация | ❌ Нет | ✅ Да |
| Server инициализация | ❌ Нет | ✅ Да |
| Actions модуль | ❌ Нет | ✅ Да (автоматический) |
| Логирование в файл | ⚠️ Требует кастомизации | ✅ Встроено |
| Автосинхронизация World | ❌ Нет | ✅ Да |

### Удаленные или изменённые методы
- Свойство `player` больше не является геттером `BedrockBot`. Используйте `bot.world.getDimension(0).players[0]` для доступа к игроку бота.
