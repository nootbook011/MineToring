# Class: BedrockBot наследует [BaseBedrockBot](./BaseBedrockBot.md)

Высокоуровневый класс для создания полнофункционального бота в Minecraft Bedrock Edition. Он объединяет управление сетевым протоколом, автоматическое хранение и синхронизацию данных о мире, сервере и игроке, а также встроенный модуль действий для выполнения команд.

## Свойства

### `world`
**Тип**: [`BedrockWorld`](./BaseBedrockWorld.md)

Экземпляр класса `BedrockWorld`, содержащий информацию о текущем мире: загруженные чанки, блоки и сущностях в зоне видимости бота. Инициализируется в методе `init()` после вызова родительского класса.

### `server`
**Тип**: [`BedrockServer`](./BedrockServer.md)

Экземпляр класса `BedrockServer`, содержащий информацию о текущем сервере: список всех игроков, техническая информация о текущем сервере. Инициализируется одновременно с `world`.

### `registry`
**Тип**: `BedrockRegistry`

Содержит класс который хранит локальные игровые данные для текущей версии из библиотеки `minecraft-data`.

### `workDir`
**Тип**: `Path | undefined`

Путь к рабочей директории бота. Используется для сохранения логов (если `logToFile` включено) и кэширования данных мира. Инициализируется из `config.botDir`.

## Динамические Свойства

### `player`
**Тип**: [`BedrockPlayer`](./BedrockPlayer.md)

Содержит класс игрока бота на сервере. Дает доступ к полной информации о игроке и его состоянии.

* **Добавляет**: плагин `ClientPacketSession`

### `actions`
**Тип**: [`ActionsBotModule`](./Versions/protocolAPI.md)

Дает доступ к высокоуровневому контролеру действий бота. Может выполнять пакетные действия и слушать высокоуровневые события.

* **Добавляет**: плагин `ActionsBotModule`
