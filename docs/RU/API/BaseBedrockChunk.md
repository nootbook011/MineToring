# Class: BedrockChunk наследует [BedrockObjectStorage](./BedrockObjectStorage.md)

Класс предназначен для хранения и обработки данных чанка. Он поддерживает работу в двух состояниях: **Raw** (сырые данные пакетов) и **Decoded** (декодированные объекты, готовые для манипуляций с блоками).

## Свойства

### `isRaw`
Булево значение. Возвращает `true`, если чанк содержит только сырые данные протокола и еще не был декодирован.

### `hasChunk`
Проверяет, содержит ли чанк полезную нагрузку (payload).

### `hasSubChunks`
Возвращает `true`, если в чанке зарегистрирован хотя бы один подчанк.

### `cache`
Булево значение. Возвращает состояние кэша чанка.

---

## Методы работы с данными

### `async decodeChunkWithAdapter(adapter)`
Основной метод для преобразования сырых данных в высокоуровневые объекты.
* **adapter**: Экземпляр адаптера (например, `BaseChunkAdapter`).
* **Процесс**: Метод декодирует основной чанк и все входящие в него подчанки, после чего переводит состояние `isRaw` в `false`.

### `toRaw()`
Сбрасывает декодированные данные и переводит чанк обратно в состояние "сырых" данных.

---

## Управление подчанками

### `subChunks`
Геттер, возвращающий объект со всеми подчанками, где ключом является координата `y`.

### `getSubChunk(y)`
Возвращает конкретный подчанк по его вертикальному индексу.

### `setSubChunk(y, bedrockSubChunk)`
Регистрирует объект подчанка в структуре чанка.

---

## Доступ к декодированным данным

Эти свойства доступны только после вызова `decodeChunkWithAdapter`.

### `DChunk`
Возвращает декодированный объект чанка (совместимый с `prismarine-chunk`).

### `DSubChunk(y)`
Возвращает декодированные данные конкретного подчанка.
