# Class: BedrockChunk наследует [BedrockObjectStorage](./BedrockObjectStorage.md)

Класс предназначен для хранения и обработки данных чанка. Он поддерживает работу в двух состояниях: **Raw** (сырые данные пакетов) и **Decoded** (декодированные объекты, готовые для манипуляций с блоками).

## Содержание
- [Свойства](#свойства)
- [Методы](#методы)

---

## Свойства

### `position`
**Тип**: `V3{ x, y, z }`

Быстрый доступ к позиции блока.

### `metadata`
**Тип**: `Object`

Объект с динамическими метаданными чанка.
Содержимое зависит от версии протокола который использует мир, [смотрите ProtocolAPI.](./Versions/protocolAPI.md)


### `hasPayload`
**Тип**: `Boolean`

Показывает на наличие полезной нагрузки в чанке.

### `hasSubChunks`
**Тип**: `Boolean`

Возвращает `true`, если в чанке зарегистрирован хотя бы один подчанк.

### `cache`
**Тип**: `Boolean`

Возвращает состояние кэша чанка.

### `subChunks`
**Тип**: `Object<Number: BedrockSubChunks>`

Возвращает объект со всеми подчанками, где ключом является координата `y`.

## Методы

### `setPayload(payload)`
Если чанк был создан через метод парсера протокола или класс `BedrockDimension`, то метод автоматически декодирует буффер данных из пакета level_chunk в соответствии с версией протокола и заполняет собственный класс данными. В остальных случаях этот метод ничего не делает и является заглушкой.

**Параметры**:
- `payload` (`Array|Buffer`): Полезная нагрузка чанка.

### `getBlockId(x, y, z, l)`
Возвращает runtimeId блока на конкретном слое чанка.

**Параметры**:
- `x` (`number`): Локальная координата X блока в чанке.
- `y` (`number`): Локальная координата Y блока в чанке.
- `z` (`number`): Локальная координата Z блока в чанке.
- `l` (`number`): Слой целевого блока.

**Возвращает**: `Number`

### `setBlockId(x, y, z, l, id)`
Устанавливает runtimeId блока на конкретном слое чанка.

**Параметры**:
- `x` (`number`): Локальная координата X блока в чанке.
- `y` (`number`): Локальная координата Y блока в чанке.
- `z` (`number`): Локальная координата Z блока в чанке.
- `l` (`number`): Слой целевого блока. 
- `id` (`number`): Новый runtimeId блока.

### `getSubChunk(y)`
Возвращает конкретный подчанк по его вертикальному индексу.

**Параметры**:
- `y` (`Number`): Y индекс подчанка в чанке.

**Возвращает**: [`BedrockSubChunk`](./BaseBedrockSubChunk.md)

### `setSubChunk(y, bedrockSubChunk)`
Регистрирует объект подчанка в структуре чанка.

**Параметры**:
- `y` (`Number`): Y индекс подчанка в чанке.
- `bedrockSubChunk` ([`BedrockSubChunk`](./BaseBedrockSubChunk.md)): Класс подчанка.
