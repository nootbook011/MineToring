# Class: BaseBedrockBot наследует [BedrockPlugins](./BedrockPlugins.md)

Ядро фреймворка MineToring, отвечающее за инициализацию клиента, управление сессиями, версиями протокола и жизненным циклом бота. Класс обеспечивает полный цикл подключения к серверу Minecraft Bedrock, включая обработку статусов, синхронизацию версий и управление плагинами.

## Статусы бота
Доступны через статический геттер `BaseBedrockBot.statusList`.

| Константа | Значение | Описание |
| :--- | :--- | :--- |
| `NotInitialized` | `0` | Бот создан, но метод `init()` еще не был вызван. |
| `Disconnected` | `1` | Бот инициализирован и готов к подключению, либо отключен от сервера. |
| `Connecting` | `2` | Процесс установки соединения с сервером (авторизация в прогрессе). |
| `Spawned` | `3` | Бот успешно заспавнился в мире и готов к взаимодействию. |

## Свойства

### `options`
**Тип**: `BotOptionsManager`

Объект конфигурации бота, содержащий настройки сервера, клиента и сети. Инициализируется в методе `init()`.

### `status`
**Тип**: `number`

Возвращает текущий числовой статус бота (0-3). Используйте `BaseBedrockBot.statusList` для получения имен статусов.

### `version`
**Тип**: `string`

Текущая версия Minecraft Bedrock, используемая ботом (например, `'1.21.50'`). Синхронизируется при инициализации путем пинга сервера или используется значение из конфигурации.

### `session`
**Тип**: `object`

Возвращает копию текущих данных сессии (UUID, XUID, ключи шифрования, PlayFab ID). Данные из этой сессии сохраняются между переподключениями.

### `packets`
**Тип**: `BotPacketController`

Геттер для доступа к контроллеру пакетов. Позволяет отправлять пакеты напрямую на сервер.

### `Protocol`
**Тип**: `ProtocolValidator.Protocol`

Геттер для доступа к загруженному протоколу текущей версии.

### `clientPacketSession`
**Тип**: `ClientPacketSession`

Геттер для доступа к обработчику пакетов клиента. Управляет входящими и исходящими пакетами автоматически.

## Методы инициализации

### `constructor()`
Создает новый экземпляр `BaseBedrockBot`. Инициализация бота выполняется в методе `init()`.

```javascript
const bot = new BaseBedrockBot()
```

### `async init(options, plugins = {})`
Основной метод для подготовки бота. Выполняет синхронизацию версии, инициализацию внутренних компонентов и загрузку плагинов.

**Параметры**:
- `options` (`BotOptionsManager | Object`): Конфигурация бота. Если передан объект, будет преобразован в `BotOptionsManager`.
- `plugins` (`Object`): Объект с кастомными плагинами. Может содержать:
  - `Logger`: Кастомный логгер
  - `ProtocolValidator`: Кастомный валидатор протокола
  - `BotPacketController`: Кастомный контроллер пакетов
  - `ClientPacketSession`: Кастомный обработчик сессии
  - `plugins` (массив или объект): Дополнительные плагины для загрузки

**Возвращает**: `Promise<void>`

**Внутренний процесс**:
1. Синхронизирует версию (с пингом сервера если необходимо)
2. Инициализирует стандартные плагины (Logger, ProtocolValidator, BotPacketController, ClientPacketSession)
3. Создает новый клиент и инициализирует обработчики состояния

## Методы управления подключением

### `async connect()`
Запускает процесс подключения к серверу.

**Процесс подключения**:
1. Дожидается завершения `init()` если бот еще не инициализирован
2. Опционально пингует сервер (если `options.network.pingBeforeConnect` = `true`)
3. Инициализирует клиент если требуется
4. Подключается к серверу
5. Вызывает `connectHandler()` из `ClientPacketSession`

**Выбрасывает**: `Error` если сервер не отвечает на пинг

### `disconnect()`
Корректно разрывает соединение с сервером.

**Процесс отключения**:
1. Вызывает `disconnectHandler()` из `ClientPacketSession`
2. Отключает клиент от сервера
3. Создает новый экземпляр клиента для возможного переподключения

### `async ping(options?)`
Пингует сервер для получения информации о версии и количестве игроков.

**Параметры**:
- `options` (`BotOptionsManager | Object`): Если не передано, использует текущие настройки `this.options`

**Возвращает**: `Promise<Object>` с полями `version`, `protocol`, `motd`, `maxPlayers`, `players`

## Методы ожидания
Полезны для синхронизации логики при запуске бота.

| Метод | Описание |
| :--- | :--- |
| `async waitUntilInit()` | Разрешается, когда `init()` завершен и статус >= `Disconnected`. |
| `async waitUntilConnect()` | Разрешается, когда статус >= `Connecting`. Отклоняется при внезапном отключении. |
| `async waitUntilSpawn()` | Разрешается, когда статус === `Spawned`. Отклоняется при внезапном отключении. |
| `async waitUntilDisconnect()` | Разрешается, когда статус <= `Disconnected`. |

**Пример**:
```javascript
await bot.init(options)
await bot.connect()
await bot.waitUntilSpawn() // Дождется, пока бот заспавнится
console.log('Bot spawned!')
```

## Методы логирования

### `log(type, message, logLevel = -1, loggerEngine?)`
Логирует сообщение через зарегистрированный логгер.

**Параметры**:
- `type` (`string`): Категория лога (например, `'debug'`, `'error'`, `'info'`)
- `message` (`string`): Текст сообщения
- `logLevel` (`number`): Уровень логирования (по умолчанию -1)
- `loggerEngine` (`Logger`): Кастомный логгер. Если не передан, использует `this.plugins.Logger`

## События

События срабатывают в ответ на изменения статуса клиента (внутренний механизм через `CustomPClient`):

| Событие | Статус | Описание |
| :--- | :--- | :--- |
| `connect_allowed` | `Disconnected` | Клиент готов к подключению |
| `session` | `Connecting` | Сессия инициирована |
| `spawn` | `Spawned` | Бот заспавнился в мире |
| `kick` | - | Бот был выгнан с сервера (вызывает `disconnect()`) |
| `close` | `Disconnected` | Соединение закрыто |

## Плагины-зависимости
Их необязательно передавать при инициализации, если вы не хотите использовать свой аналог.

* **Logger**: Вспомогательный класс для логирования событий бота.
* **BotPacketController**: Контроллер для отправки пакетов на сервер.
* **ProtocolValidator**: Динамически загружает и кэширует данные протокола под конкретную версию игры.
* **ClientPacketSession**: Обеспечивает автоматическое управление входящими и исходящими сетевыми пакетами.

## Примеры использования

### Базовая инициализация и подключение
```javascript
import { BotOptions } from 'minetoring'

const bot = new BaseBedrockBot()

const options = {
    server: {
        host: 'localhost',
        port: 19132,
        version: '1.21.50'
    },
    client: {
        username: 'TestBot'
    },
    network: {
        pingBeforeConnect: true
    }
}

await bot.init(options)
await bot.connect()
await bot.waitUntilSpawn()
console.log(`Bot spawned! Current status: ${bot.status}`)

await bot.disconnect()
```

### Работа с кастомными плагинами
```javascript
class MyCustomLogger {
    createLog(type, msg, level) { }
    print() { }
    write() { }
}

const plugins = {
    Logger: new MyCustomLogger()
}

await bot.init(options, plugins)
```

### Пинг сервера перед подключением
```javascript
const pingData = await bot.ping({
    server: {
        host: 'realm.example.com',
        port: 19132
    }
})

console.log(`Версия: ${pingData.version}`)
console.log(`Онлайн: ${pingData.players}/${pingData.maxPlayers}`)
```
