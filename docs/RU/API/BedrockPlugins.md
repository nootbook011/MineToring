# Class: BedrockPlugins

Базовый класс, реализующий систему плагинов и модулей. Он позволяет динамически расширять возможности бота или хранилищ, предоставляя централизованный механизм для регистрации, выгрузки и доступа к различным компонентам (например, логгерам, адаптерам или контроллерам пакетов).

## Свойства

### `plugins`
Возвращает прокси-объект, предоставляющий доступ ко всем загруженным плагинам по их именам.
* **Примечание**: Прямая запись в этот объект (например, `this.plugins.myPlugin = ...`) запрещена и вызовет `PluginError`.

### `loadedPlugins`
Возвращает копию (объект) всех текущих зарегистрированных плагинов.

### `pluginsList`
Возвращает массив имен всех загруженных плагинов.

## Методы загрузки плагинов

### `loadPlugin(plugin, name? = undefined)`
Регистрирует один плагин в системе.
* **plugin**: Экземпляр плагина или класс, наследующий `BaseModule`. Если передан класс, он будет автоматически инициализирован с передачей текущего экземпляра `BedrockPlugins` в конструктор.
* **name**: Имя, под которым плагин будет доступен. Если не указано, используется свойство `name` плагина или имя его конструктора.

### `loadPlugins(plugins)`
Массовая загрузка плагинов.
* **plugins**: Может быть объектом `{ name: pluginInstance }` или массивом экземпляров плагинов.

---

## Методы управления

### `unloadPlugin(plugin)`
Удаляет плагин из системы.
* **plugin**: Объект плагина, имеющий свойство `name`. После вызова плагин больше не будет доступен через свойство `.plugins`.
