# Class: BedrockPlugins

Базовый класс, реализующий систему плагинов и модулей. Он позволяет динамически расширять возможности бота или хранилищ, предоставляя централизованный механизм для регистрации, выгрузки и доступа к различным компонентам (например, логгерам, адаптерам или контроллерам пакетов).

## Свойства

### `plugins`
**Тип**: `Proxy<Object>`

Возвращает прокси-объект, предоставляющий доступ ко всем загруженным плагинам по их именам.

### `loadedPlugins`
**Тип**: `Object`

Возвращает копию всех текущих зарегистрированных плагинов.

### `pluginsList`
**Тип**: `Array<String>`

Возвращает массив имен всех загруженных плагинов.

## Методы

### `loadPlugin(plugin, name? = undefined)`
Регистрирует один плагин в системе.

**Параметры**:
- `plugin` (`Class|BaseModule`): Экземпляр плагина или класс, наследующий `BaseModule`. Если передан класс, он будет автоматически инициализирован с передачей текущего экземпляра `BedrockPlugins` в конструктор.
- `name` (`String|undefined`): Имя, под которым плагин будет доступен. Если не указано, используется свойство `name` плагина или имя его конструктора.

### `loadPlugins(plugins)`
Массовая загрузка плагинов.

**Параметры**:
- `plugins` (`Array<Plugin>|Object<String: Plugin>`): Плагины для загрузки. Может быть объектом `{ name: pluginInstance }` или массивом экземпляров плагинов.

### `unloadPlugin(plugin)`
Удаляет плагин из системы.

**Параметры**:
- `plugin` (`Class|BaseModule`): Объект загруженого плагина для выгрузки. После вызова плагин больше не будет доступен через свойство `.plugins`.
