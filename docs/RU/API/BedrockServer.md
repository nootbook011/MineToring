# Class: BedrockServer

**Статус**: Зарезервирован для будущего развития (в настоящее время пустой класс)

Класс предназначен для управления и хранения информации о сервере Minecraft Bedrock. В будущих версиях фреймворка здесь будут методы для работы с игроками, правилами сервера, метаданными и другой серверной информацией.

## Текущее состояние

На версии **0.6.1** класс `BedrockServer` является пустым контейнером (заготовкой).

```javascript
export class BedrockServer {
    
}
```

**Примечание**: Класс инициализируется в `BedrockBot` и доступен через геттер `bot.server`, но в настоящее время он не содержит функциональности.

---

## Планируемые функции

В будущих версиях ожидается добавление следующей функциональности:

### Управление игроками
- Получение списка всех игроков на сервере
- Информация об игроке (имя, UUID, позиция)
- События присоединения/отключения игроков

### Информация о сервере
- Метаданные сервера (MOTD, версия, максимум игроков)
- Правила сервера (PVP включена, режим приватности и т.д.)
- Состояние сервера (онлайн, оффлайн)

### Игровые данные
- Время суток и погода
- Уровень сложности
- Режим игры (Survival, Creative, Adventure)
- Состояние игровых элементов

### События сервера
- Событие подключения/отключения игрока
- Событие изменения параметров сервера
- События игровых элементов (иници, погода и т.д.)

## Как это используется

### В BedrockBot
```javascript
const bot = new BedrockBot()
await bot.init(options)
await bot.connect()

// Доступ к серверу (в настоящее время пусто)
const server = bot.server
console.log(server) // BedrockServer {}
```

### Инициализация
Класс инициализируется в `BedrockBot.#initStorage()` с переданными плагинами:

```javascript
#initStorage() {
    const plugins = {
        ProtocolValidator: this.plugins.ProtocolValidator,
        ValidateAdapter: this.plugins.ValidateAdapter || new PrismarineAdapter(this.version),
        BlobsManager: this.options?.client?.settings?.cache ? BedrockBlobsManager : undefined
    }
    this.#world = new World(this.version, plugins)
    this.#server = new Server(this.version, plugins)  // ← Здесь инициализируется
}
```

## Архитектурные заметки

- Класс наследуется ожидаемо от `BedrockPlugins` для поддержки системы плагинов
- Будет синхронизироваться с данными из измерения (`BedrockDimension.players`)
- Предполагается использование `EventEmitter` для генерации событий
